# Radar de Opinión LinkedIn · Miracle AI

Página estática (HTML/CSS/JS puro, sin build) con la Edición 01 del radar de opinión: seis noticias médicas verificadas, cada una convertida en un artículo de opinión listo para copiar y publicar en LinkedIn, más una guía de calendario de publicación.

## Contenido

- `index.html` — la página completa (estilos y lógica de "copiar post" incluidos, sin dependencias externas).

## Uso local

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático:

```bash
npx serve .
```

## Despliegue

No requiere build. Cualquier hosting de estáticos (Vercel, Netlify, GitHub Pages) puede servir `index.html` en la raíz sin configuración adicional.
